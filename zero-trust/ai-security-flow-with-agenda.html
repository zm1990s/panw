SCENARIO 02待展示

Prompt Injection 防护

用户输入恶意指令，试图绕过规则并获取系统提示，观察攻击如何被拦截。

  • 浏览器提交含注入指令的请求
  • 身份验证通过，进入 Gateway
  • PRISMA AIRS 检测 Prompt Injection
  • 拦截攻击，不转发模型或工具
  • 返回安全提示，记录攻击事件
展示结果：注入攻击被拦截，正常规则保持有效
SCENARIO 03待展示

模型故障 · 自动切换

主模型调用超时，观察 Gateway 如何切换备用模型并继续响应。

  • Primary + Failover 路由策略
  • 主模型调用失败或超时
  • 自动切换至预配置的备用模型
  • 响应完成运行时安全检测
  • 记录模型失败、切换与响应轨迹
展示结果：备用模型接续服务，用户获得响应
